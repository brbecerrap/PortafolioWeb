# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es/1.0.0/),
y este proyecto adherido a [Semantic Versioning](https://semver.org/lang/es/).

## [1.1.0] - 2026-07-27

### Agregado

- Modo oscuro con toggle en el header
- Persistencia de preferencia de tema en localStorage
- Detección automática de preferencia del sistema (prefers-color-scheme)
- CSS personalizado con variables para temas claro/oscuro
- Hoja de estilo para impresión (siempre modo claro)
- Indicadores de foco para navegación por teclado
- Transiciones suaves al cambiar de tema
- Avatar basado en icono (User) en lugar de imagen de perfil
- Eliminación de todas las dependencias de imágenes

### Cambiado

- Hero: avatar de imagen a icono User con iniciales
- Proyectos: eliminadas imágenes de tarjetas
- Todos los componentes actualizados con CSS variables para soporte de temas

## [1.0.0] - 2026-07-27

### Agregado

- Estructura inicial del proyecto con Vite + React + TypeScript
- Configuración de Tailwind CSS para estilos
- Sección Hero con perfil profesional y contacto
- Sección de Habilidades organizadas por categoría:
  - Desarrollo Web y Software
  - Microsoft Power Platform
  - Bases de Datos
  - Metodologías y Herramientas
- Sección de Proyectos destacados:
  - Bot de WhatsApp para Gestión de Usuarios
  - Soluciones Empresariales con Power Platform
- Sección de Experiencia Profesional con timeline
- Sección de Educación y Certificaciones
- Sección de Contacto
- Navegación responsive con menú hamburguesa
- ScrollSpy para sección activa
- Optimización para Core Web Vitals
- Meta tags SEO y Open Graph
- Soporte para lectores de pantalla
- Fallback para navegadores sin JavaScript
